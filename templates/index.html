Bukti Arsitektur & Kepatuhan Praktikum
1. Network Isolation (Internal Database)

Service database (MySQL 8.4) tidak mengekspos port 3306 ke publik. MySQL berada di network internal (internal_network) dan hanya dapat diakses secara privat oleh service app melalui hostname database.

2. Volume Persistence

Semua data temuan dan tabel disimpan di dalam named volume db_data. Saat container dimatikan via docker compose down dan dijalankan kembali via docker compose up -d, data tetap utuh.

3. Healthcheck & Depends_On

Service database dilengkapi mysqladmin ping healthcheck. Service app menunggu hingga status database berstatus service_healthy sebelum mulai melayani request HTTP.

4. Zero Plaintext Secret (.env)

Password root, password user, dan secret key dimuat dari file .env yang tidak masuk ke repositori git (sudah disertakan .env.example).
